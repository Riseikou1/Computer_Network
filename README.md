# Computer Networks Design Project: P2P Messenger

This project implements the required multi-user messenger system:

- A **login server** stores online users: ID, IP address, and port number.
- A **client program** registers itself with the login server and receives the online user list.
- Messages are sent **directly between clients**, not through the login server.
- The text UI supports the required three functions: invite user, end session, and broadcast messages to all session users.
- Messages use an HTTP-like format with headers and body.

## File structure

```text
src/
  protocol.py       HTTP-like message builder/parser
  login_server.py   central online-user registry
  client.py         peer-to-peer messenger client
data/
  online_users.json generated by the login server
docs/
  team_report.pptx  project explanation slides
  demo.html         YouTube demo URL placeholder
```

## Run demo locally

Open three terminals from the `src` directory.

### Terminal 1: login server

```bash
python3 login_server.py --host 127.0.0.1 --port 9000
```

### Terminal 2: Alice

```bash
python3 client.py --id alice --listen-port 5001 --server-port 9000
```

### Terminal 3: Bob

```bash
python3 client.py --id bob --listen-port 5002 --server-port 9000
```

## Client commands

```text
users              show online users
invite <user_id>   invite a user to this messenger session
session            show users in current session
send <message>     broadcast a message to all users in session
end                end the current session
help               show commands
quit               unregister and exit
```

## Example flow

In Alice terminal:

```text
users
invite bob
send hello bob
end
quit
```

Bob receives the invite and messages directly from Alice's client process.

## Message format example

```text
Command: MESSAGE
From: alice
To: bob
Content-Length: 9

hello bob
```

The protocol separates headers and body using a blank line, similar to HTTP messages.
